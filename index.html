このアプリについて

このWebアプリは、画像、ドキュメント、その他のファイルをDataURL（データURL）形式に簡単に変換します。 ほとんどのファイル形式に対応しており、選択されたファイルはあなたのブラウザ内のみで処理され、外部サーバーに送信されることは一切ありません。安心してご利用いただけます。

使い方

  1. 上のエリアにファイルをドラッグ＆ドロップするか、クリックしてファイルを選択します。
  2. ファイルが自動的にDataURLに変換されるのを待ちます（処理中インジケーターが表示されます）。
  3. 結果欄にDataURLが表示されたら、「コピー」ボタンでクリップボードにコピーできます。

DataURLとは

データ URL は data: スキームが先頭についた URL で、小さなファイルをインラインで文書に埋め込むことができます。

出典: MDN Web Docs

DataURLは、ファイルの内容そのものをURL文字列として表現する方法です。これにより、CSSやHTMLに小さな画像などを直接埋め込むことができ、外部ファイルへのリクエスト数を減らすことができます。
注意: DataURLは元のファイルサイズよりも大きくなる傾向があります（Base64エンコードのため約33%増加）。大きなファイルをDataURLに変換して共有する目的には適していません。あくまでWebページ内でのリソース埋め込みなどに利用するのが一般的です。
